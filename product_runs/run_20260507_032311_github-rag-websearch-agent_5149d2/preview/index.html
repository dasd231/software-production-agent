软件生产在当前 run workspace 内生成或改进用户产物。
沙箱运行测试只在产物目录内运行可控 smoke check，不触碰平台源码。
交付封装更新 README、交付清单、预览入口和 ZIP 可下载产物。
GitHub 项目搜索器检索参考项目，记录 license/star/更新时间筛选依据。
RAG 检索问答用本地产物和参考资料回答实现问题并给出引用。
Web Search 补充学习只在需要最新资料/文档时联网补证据。
Agent 编排把学习、生成、验证、修复合成一条可复盘流水线。
