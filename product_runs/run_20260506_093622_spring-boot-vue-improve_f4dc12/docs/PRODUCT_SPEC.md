# 产品规格说明：人员管理系统

## 目标

基于上一版软件方案继续改进，不要从零开始。 上一版 run: run_20260506_093601_spring-boot-vue-improve_abc93

## 典型角色

- 人事管理员：维护员工档案、部门、岗位和状态。
- 薪酬专员：查看工资字段、核对薪资区间和发薪周期。
- 部门负责人：按部门筛选人员，跟踪岗位流转。
- 系统管理员：后续接入账号、权限、审计和数据备份。

## 核心业务闭环

1. 新员工入职：录入姓名、部门、岗位、工资、状态。
2. 员工变更：编辑部门、岗位、薪资或在职状态。
3. 员工离职：删除或标记离职，并保留审计扩展点。
4. 组织配置：查询部门、岗位和薪资规则参考数据。
5. 业务验收：前端可筛选、搜索、增删改；后端提供 REST CRUD；测试覆盖核心 CRUD 流程。

## 当前边界

- 数据使用内存存储，适合毕业设计原型和产品验收演示。
- `docs/DATABASE_SCHEMA.md` 给出后续落库设计。
- 鉴权、操作审计、导入导出、分页和持久化数据库是下一阶段。
