This is a quota-free scaffold generated by the product UI offline mode. It is not an
LLM result; it exists so the product shell can be tested even when API quota is exhausted.

## Product Scope

- Employee CRUD: create, list, update and delete staff records.
- Organization reference data: departments, positions and payroll rules.
- Frontend API wrapper with local fallback when the backend is not running.
- Static sandbox preview for product review without executing build scripts.
- Delivery docs: product spec, API contract, database schema and checklist.
- Login page, demo account, role permission badges and Auth API.

- Approval workflow module with approval list and approve action.
- Import/export module for employee exchange workflows.
- Operation audit log module for sensitive actions.


## Backend

```bash
cd backend
mvn spring-boot:run
```

Endpoints:

- `GET /api/health`
- `GET /api/features`
- `GET /api/employees`
- `POST /api/employees`
- `PUT /api/employees/<built-in function id>`
- `DELETE /api/employees/<built-in function id>`
- `GET /api/reference/departments`
- `GET /api/reference/positions`
- `GET /api/reference/payroll-rules`
- `POST /api/auth/login`
- `GET /api/auth/me`
- `POST /api/auth/logout`

- `GET /api/workflows/approvals`
- `POST /api/workflows/approvals/{id}/approve`
- `POST /api/exchange/employees/import`
- `GET /api/exchange/employees/export`
- `GET /api/audit/logs`
