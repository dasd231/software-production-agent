7.2 最小可行产品（MVP）演示流程

从用户输入需求到生成预览、打包下载、审计追踪的完整闭环。

1
场景：在产品 UI 输入“开发一个图书管理系统/待办系统”。
2
规划：系统完成 token 估算、模型路由、上下文预算和队列准入。
3
执行：任务进入队列，失败可重试，多次失败进入死信队列。
4
验证：生成 iframe 沙盒预览，可继续改进或下载 ZIP。
5
审计：支付、任务、下载、限流等关键动作写入审计日志。
