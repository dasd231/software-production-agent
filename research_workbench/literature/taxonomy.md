# 同行论文阅读分类

论文阅读先按研究问题分类，而不是先按模型名字分类。

| 类别 | 关注点 |
| --- | --- |
| Project Understanding | 仓库级理解、模块定位、代码结构问答 |
| Evidence Grounding | 引用、证据检索、证据忠实 |
| Multi-hop Evidence Reasoning | 多证据推理、证据链重建 |
| Agent Operations | 工具选择、状态诊断、失败恢复 |
| Code / Repository Representation | 代码编码、仓库编码、结构表达 |
| Retrieval-Augmented Modeling | RAG、外部记忆、上下文融合 |
| Method Innovation | encoder、cross-attention、fusion、graph 等 |
| Evaluation & Benchmarking | 数据集、指标、基准设计 |

## 推荐记录方式

每篇论文至少回答 5 个问题：

1. 它解决的是哪个任务；
2. 它的输入表示是什么；
3. 它如何建模证据或项目结构；
4. 它用什么指标证明自己；
5. 它给我的工作留下了什么空间。
