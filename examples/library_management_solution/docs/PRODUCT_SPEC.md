# Product Spec

## User roles

- Librarian: manages books, readers and circulation.
- Manager: adjusts fine rules, exports reports, handles exceptions.
- Auditor: reads operation logs and sensitive actions.

## Main pages

1. Dashboard
2. Book catalog
3. Reader cards
4. Borrow / return desk
5. Reservation queue
6. Fine bills
7. Audit logs

## Acceptance criteria

- Can search books by ISBN, title, author and category.
- Can borrow and return a concrete book copy.
- Can calculate overdue fine once and only once.
- Can view dashboard indicators.
- Can export audit-friendly operation logs.
