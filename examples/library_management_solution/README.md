# Library Management System Solution

A curated, demo-ready solution for showing the Software Studio workflow.

## Modules

- Book catalog: ISBN, title, author, category, location, stock, status.
- Reader management: reader card, contact, borrow limit, blacklist flag.
- Circulation workflow: borrow, return, renew, reserve, cancel reservation.
- Fine rules: overdue days, fine rate, exemption, payment status.
- RBAC: librarian, manager, reader-service, auditor.
- Dashboard: stock alerts, overdue ranking, monthly borrow trend.
- Audit log: every borrow/return/fine adjustment is traceable.

## Why it is useful for demos

This is not a toy CRUD example. It has entities, state transitions, permission rules,
reports, risk controls and tests. It is easy to understand in an interview and still
rich enough to demonstrate enterprise thinking.
